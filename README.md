# Fruit Quality Classification using Deep Learning

## Overview
This project implements a Convolutional Neural Network (CNN) for classifying fruit quality (good vs bad).

## Motivation
Inspired by my PhD research in image-based quality detection, this project explores optimization-aware deep learning models.

## Methods
- CNN model using TensorFlow
- Image preprocessing and normalization
- Optimization comparison: Adam vs SGD

## Results
- Adam optimizer showed faster convergence
- SGD provided stable learning with slower convergence

## Tools Used
- Python
- TensorFlow
- Google Colab
